# Duoveil

A little magic for your MacBook. Your desktop bends and softly blurs as you close the lid.

[Duoveil on Gumroad](https://7517229897335.gumroad.com/l/duoveil)

## Updates

This repository hosts Duoveil’s signed update feed and release downloads.
[Download Duoveil 1.0.0 (build 23)](https://github.com/esgvio/Duoveil/releases/download/v1.0.0-build.23/Duoveil-1.0.0-23-arm64.dmg)

Build 23 adds usage and reliability statistics through TelemetryDeck to help
improve Duoveil. Existing installations can update from
**Check for Updates…** in Duoveil’s menu.

The Gumroad edition requires a license key to enable the effect.
Requires macOS 14 or later, Apple silicon, and a readable MacBook lid-angle sensor.

## Privacy

Screen images stay in memory on your Mac. Duoveil sends license activation and
verification requests to Gumroad and checks this repository for signed updates.

TelemetryDeck reports cover launches, onboarding, effect usage, settings,
recommendation clicks and errors. They include app version, Mac model,
architecture, macOS version, time zone, language and locale, and use a hashed
random installation identifier. Screen content, license keys, file paths,
serial numbers and account information are excluded from these reports.
